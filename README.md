# Y N Classes — Static Website

This is the simplified static information website for Y N Classes.

## Run locally

```bash
npm install
npm start
```

Open http://localhost:3000

## Included

- Home / information website
- Results / toppers section
- About / programs information
- Contact page
- Privacy policy
- Refund policy
- Terms of use
- Existing Y N Classes images/assets

There is no login, dashboard, exam system, results portal, solutions portal, courses portal, admin panel, Supabase dependency, Razorpay dependency, or Next.js runtime in this version.
